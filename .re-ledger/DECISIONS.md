# Decisions

- **D01 Go.** Go suits concurrent I/O and embedded CLI/web/MCP distribution. net/http, encoding/json, os/exec and html/publicsuffix parsing cover the task with one external module. Rust would also compile native binaries but introduces a larger dependency and async runtime surface for this workload. No performance advantage is asserted. R02, R06, R10.
- **D02 Source-informed MIT rebuild.** The upstream source is public and MIT-licensed. All runtime implementation is Go plus browser HTML/CSS/JS. Original analyst playbooks and the demo capture are embedded with upstream license and attribution. No strict clean-room separation is asserted. R01–R05.
- **D03 Explicit source limits.** Fetch bounded public HTTPS/HTTP resources with verified DNS destinations, timeouts, redirect validation, and source-level unknowns. General web traffic does not use an implicit environment proxy. Each run assigns stable citation IDs in collector order, even when requests run concurrently. R05, R10.
- **D04 Immutable local snapshots.** Each run is atomically published to its own directory with both Markdown and JSON. Dates alone cannot identify a run. Web and MCP share history, and a failed run with no observations remains inspectable.
- **D05 Scope for inference.** Pixels may support a likely signal. Unknown ad activity cannot imply dormancy. Partial or missing samples cannot show a campaign ended. Keep source scopes, sample sizes and provenance visible.
- **D06 User surfaces.** Original loopback interface with cancellable polling, saved evidence and downloads. Source keys are supplied through the environment. No automatic client settings changes during verification. Strategy reports require passing a structural citation and grounding check before publication.
- **D07 Tool routing.** No callable /swrm or native Antigravity Swarm action was found on this host. Per REM fallback, used native delegated workers for collectors, paid/free provider adapters, MCP and UI with disjoint package ownership. Coordinator owns contracts, merge, checks, and handoff. No separate /goal interface was callable, so PROJECT.md and STATUS.md hold the mission. get-fable v1.17.2 selected TDD. Superpowers TDD and verification guidance was read. The dependency DAG covers the get-things-done route; an independently callable command was not discovered. Architecture decisions and this ledger cover the optional decision-capture route.
- **D08 Credentialed verification.** Paid collectors and writers support bounded fixtures. Key availability was checked without displaying values. No live paid requests or authenticated report generations were triggered in delivery checks.
